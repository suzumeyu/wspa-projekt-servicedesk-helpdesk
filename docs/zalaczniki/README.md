# Załączniki — makiety interfejsu (opcjonalnie)

Makiety nie są obowiązkowe, ale są **mile widziane**: mogą podnieść ocenę w kryterium „Zwarty dokument”. Zalecane są 2–3 kluczowe ekrany, powiązane z wymaganiami i procesami.

**Narzędzia (przykłady):** Figma, Excalidraw, Penpot, draw.io (biblioteka *Mockups*), także czytelny szkic odręczny zeskanowany do PNG.

**Zasady:**

- Plik graficzny (PNG/SVG) w tym katalogu. Jeśli narzędzie ma format źródłowy, dołącz go albo podaj link do projektu (np. Figma, z dostępem do odczytu).
- Każda makieta ma identyfikator i opis według tabeli poniżej.

**Inne pliki w tym katalogu (obowiązkowe przed sesją odbiorczą):**

- `prezentacja.pdf` — prezentacja na obronę (sesja odbiorcza w BBB); w razie awarii łącza prowadzący wyświetli ją z repozytorium.
- `protokol_odbioru.md` — protokół zdawczo-odbiorczy (wzór `S10_protokol_zdawczo_odbiorczy.md`), dodany osobnym PR z gałęzi `docs/protokol-odbioru`; akceptowany na sesji odbiorczej przez *Approve* PM i *Approve* + scalenie przez prowadzącego.
